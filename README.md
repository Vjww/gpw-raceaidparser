# gpw-raceaidparser

A text file parser for Grand Prix World (GPW) that exports the race debug output (the RaceAID.txt file) to a CSV file and attempts to clean up rogue lap entries. The resulting CSV file can be used for graphing various race metrics for analysis and comparison.

This .NET 10 Console App (C#) does not have an installer and is intended to be run through an IDE like Visual Studio or VSCode. Further changes may be required to the code to export the race metrics of interest.
